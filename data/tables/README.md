# Lookup tables

Code-to-name tables used when exporting to other tools. They change no values.

| File | Contents | Source |
| --- | --- | --- |
| `igbp_lc_type1.csv` | MCD12Q1 `LC_Type1` (IGBP) class codes 1–17, abbreviations and names | MODIS Land Cover Type Product (MCD12Q1) Collection 6.1 User Guide, Table 3 (Sulla-Menashe & Friedl), https://lpdaac.usgs.gov/documents/1409/MCD12_User_Guide_V61.pdf |
| `gldas_fao16_texture.csv` | GLDAS/Noah 16-category soil texture codes and USDA/FAO class names | GLDAS soils page, https://ldas.gsfc.nasa.gov/gldas/soils |
